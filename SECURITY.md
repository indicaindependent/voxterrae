# Security policy

Please report vulnerabilities privately to security@voxterrae.app (see https://voxterrae.app/.well-known/security.txt). Include the version, networks involved, steps to reproduce and impact. Acknowledgement within 72 hours; fix or timeline within 14 days for anything affecting message confidentiality, certificate handling or remote code execution. Please allow that window before publishing.

In scope: the VoxTerrae client, the hub website and its feeds. Out of scope: the EFnet servers (not ours).
